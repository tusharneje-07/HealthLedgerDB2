DB2 Query Server API Documentation

Dark-mode, detailed API reference for all endpoints

Overview

The DB2 Query Server API allows executing SQL queries against a DB2 database via RESTful endpoints. You can perform SELECT, RUN (INSERT, UPDATE, DELETE, DDL), and DESCRIBE operations.

All queries are executed under the schema: NEJET.

DB2 Connection Configuration

This section explains the DSN (Data Source Name) configuration used to connect the Flask API to the DB2 database.


dsn_hostname = "localhost"      # DB2 server hostname or IP
dsn_uid = "db2admin"            # Username for authentication
dsn_pwd = "2425455"             # Password for the DB2 user
dsn_database = "HOSPITAL"       # Target database
dsn_port = "25000"              # DB2 listening port
dsn_protocol = "TCPIP"          # Communication protocol
schema = "NEJET"                # Default schema for queries

dsn = (
    f"DATABASE={dsn_database};"
    f"HOSTNAME={dsn_hostname};"
    f"PORT={dsn_port};"
    f"PROTOCOL={dsn_protocol};"
    f"UID={dsn_uid};"
    f"PWD={dsn_pwd};"
)

Example Python usage:


import ibm_db

conn = ibm_db.connect(dsn, "", "")
if conn:
    print("Connected successfully!")
    ibm_db.close(conn)
else:
    print("Connection failed.")

API Endpoints

1. GET /get/run/<query>


GET http://localhost:9999/get/run/INSERT%20INTO%20PATIENT_DATA(ID,NAME)%20VALUES(1,'John')

2. GET /get/select/<query>


GET http://localhost:9999/get/select/SELECT%20*%20FROM%20PATIENT_DATA

3. GET /get/describe/<table_name>


GET http://localhost:9999/get/describe/PATIENT_DATA

4. POST /post/

Execute SQL queries using JSON payload. Payload must include:

FieldTypeDescription
typestringQuery type: select, run, describe
querystringThe SQL query or table name for describe

Example payload:


{
    "type": "select",
    "query": "SELECT * FROM PATIENT_DATA"
}

Example Responses

Success (SELECT)


{
  "status": true,
  "data": [
    {"ID": 1, "NAME": "John"},
    {"ID": 2, "NAME": "Alice"}
  ]
}

Success (RUN)


{
  "status": true,
  "data": "Query executed successfully"
}

Error Response


{
  "status": false,
  "message": "Table does not exist"
}

Example Usage (JavaScript)


const sqlQuery = "SELECT * FROM PATIENT_DATA";
const payload = { type: "select", query: sqlQuery };

fetch("http://localhost:9999/post/", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(payload)
})
.then(res => res.json())
.then(data => console.log(data))
.catch(err => console.error(err));
